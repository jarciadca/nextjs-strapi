\# Next.js + Strapi Training Project



A hands-on training project to learn how to connect a \*\*Next.js 16\*\* frontend with a \*\*Strapi 5\*\* headless CMS. This project covers data fetching, dynamic zones, components, nested populate queries, and error handling.

\## 🎯 What You'll Learn



By the end of this project, you'll understand:



\- How to set up a \*\*Strapi 5\*\* headless CMS with Single Types, Collection Types, and Components

\- How to create a \*\*Dynamic Zone\*\* with reusable components

\- How to fetch data from Strapi in a \*\*Next.js Server Component\*\*

\- How to build \*\*nested populate queries\*\* with `qs`

\- How to handle \*\*Strapi 5 query syntax\*\* (different from Strapi 4)

\- How to handle \*\*errors gracefully\*\* so the frontend doesn't crash

\- How to \*\*type\*\* Strapi responses with TypeScript
